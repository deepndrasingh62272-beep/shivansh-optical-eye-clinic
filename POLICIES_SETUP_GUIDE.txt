HOW TO EDIT POLICIES:
=====================

1. Open file: src/config/policies.ts
2. Edit the content of:
   - privacy_policy
   - terms_of_service
   - refund_policy
3. Save the file
4. Refresh your website
5. Changes will be reflected immediately

NO DATABASE NEEDED!
===================

- Policies are now stored in a TypeScript config file
- No Supabase migration required
- No database calls
- No error issues
- Completely local and fast

2. Run this SQL in Supabase SQL Editor:

ALTER TABLE store_settings
ADD COLUMN IF NOT EXISTS privacy_policy text,
ADD COLUMN IF NOT EXISTS terms_of_service text,
ADD COLUMN IF NOT EXISTS refund_policy text;

3. Uncomment the PoliciesTab component in src/components/AdminDashboard.tsx
4. Uncomment the policies tab in the tabs array
5. Uncomment the tab rendering
