# Shivansh Optical Eye Clinic

A modern web application for an optical clinic with appointment booking, product catalog, and admin dashboard.

**Created by: Dipendra Singh**

## Features

- Modern responsive design
- Appointment booking system
- Product catalog for eyewear
- Shopping cart and checkout
- Admin dashboard
- WhatsApp integration
- Special offers and promotions
- Store location information

## Technologies Used

- React + TypeScript
- Tailwind CSS
- Vite
- Supabase (Backend)
- ESLint for code quality

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Project Structure

```
src/
├── components/     # React components
├── config/         # Configuration files
├── data/          # Static data
├── hooks/         # Custom React hooks
├── lib/           # Utility libraries
├── store/         # State management
└── types.ts       # TypeScript types
```
